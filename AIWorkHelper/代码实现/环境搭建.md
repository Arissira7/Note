# 环境搭建

## 1. 软件版本

| **软件**      | **版本**              |
| ----------- | ------------------- |
| Go          | `1.22.0` 或以上版本      |
| Redis       | `6.x` 或以上版本         |

| Docker      | 版本无特殊要求，推荐使用社区最新稳定版 |

# 1. Docker安装

1. 以下是在 `CentOS` 系统上安装Docker的详细步骤

```shell
# 1. 安装必要的工具
# yum-utils 提供了 yum-config-manager 工具
# device-mapper-persistent-data 和 lvm2 是devicemapper存储驱动所需要的依赖
sudo yum install -y yum-utils device-mapper-persistent-data lvm2

# 2. 添加Docker的官方软件源
# 这样我们就可以直接通过yum来安装最新版的Docker了
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 3. 安装Docker Community Edition (CE)
sudo yum install -y docker-ce

# 4. 启动Docker服务并设置为开机自启
sudo systemctl start docker
sudo systemctl enable docker

# 5. (可选但强烈推荐) 配置国内镜像加速器
# 由于网络原因，直接从Docker Hub拉取镜像可能会非常慢甚至失败
# 我们可以配置一个国内的镜像源来加速
# 创建或修改 /etc/docker/daemon.json 文件
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://<your-mirror-accelerator>.mirror.aliyuncs.com"]
}
EOF
# 请将 <your-mirror-accelerator> 替换为你自己的阿里云等平台的加速器地址

# 6. 重启Docker服务使配置生效
sudo systemctl daemon-reload
sudo systemctl restart docker
```

以上是一个详细版本的docker安装，有些工具不是必要的，如果执行过程中有问题的话，可以直接在docker官网：<https://www.docker.com/下载安装，直接安装成功即可。对于docker不是很熟悉的话，也可以现在这里学习下：>

## 1.1 Redis安装

环境准备好后，需要来部署Redis。前面说过，这个redis最好是`6.x` 或以上版本，要包含我们需要的 `RedisSearch` 插件。执行以下命令安装

```shell
docker run -itd -p 6379:6379 --name redis redis/redis-stack-server:latest
```

# 2. MongoDB安装

```go
docker run -d --name aiworkhelper-mongodb -p 27017:27017 mongo:7.0
```

执行上述命令安装Mongodb，本地端口映射为27017，安装的是7.0版本。执行成功之后可以用MongoDB Compass这个Mongodb的可视化软件来查看下Mongodb状态，MongoDB Compass下载地址：<https://www.mongodb.com/products/tools/compass>
