后续项目中的AI功能我们需要用到大模型，我们选择阿里的通义千问大模型来完成本次项目。我们首先在阿里百炼大模型广场选择我们要使用的大模型：https://bailian.console.aliyun.com/?tab=model#/model-market。没有登陆的话，首先点击右上角的注册登陆。

登陆完成之后，这里我们选择通义千问3-Max-Preview这个模型，点击API参考查看他的API用法。

![](<images/3. 通义千问API Key注册-image.png>)

如果我们还没有获取API KEY的话，点击获取API Key

![](<images/3. 通义千问API Key注册-image-1.png>)

点击获取API KEY就会来到以下页面https://bailian.console.aliyun.com/?tab=api#/api/?type=model\&url=2712195，按照这个页面指引步骤获取API Key即可

![](<images/3. 通义千问API Key注册-image-2.png>)

获取完成之后就可以在密钥管理页面查看我们获取到的API Key。在上述页面点击密钥管理进入到密钥管理也main

![](<images/3. 通义千问API Key注册-image-3.png>)

这里就可以查看到我们刚刚获取到的密钥了，这个也是我们后续在项目中需要用到的

![](<images/3. 通义千问API Key注册-image-4.png>)
