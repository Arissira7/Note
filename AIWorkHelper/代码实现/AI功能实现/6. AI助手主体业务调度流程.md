# 1. AI业务与主体业务的关系

在 **AI聊天助手（AIChat）** 的业务中，用户向 AIChat 发送消息的时候，该消息内容分为两大块：

* **通用消息**：就像我们与 chatGPT聊天一样，不涉及业务

* **AI 生成业务**：用户输入相关提示词，由 AI 去完成业务。

在 AI 生成业务中，会根据用户的提示词需要选择对应主体业务中的方法去完成。

![](<images/6. AI助手主体业务调度流程-主体-AI.png>)

通过前面的分析，我们基本已经确定 **AI 助手是需要依托主体业务而去实现**，顾就必然会涉及到对主体业务方法的调用。因此 **AI 采取什么方式调用主体业务呢？**

# 2. **AI如何调用主体业**

![](<images/6. AI助手主体业务调度流程-image.png>)

在目前的技术架构流程方案中，我们将通过 **RouterChain** 对用户的提示词分发，根据提示词的特征分发给相应的 **Chain** 去执行。

该 **Chain** 是一组共同特点的业务集合对象，在这里我们可以运用 **agent**。比如待办的处理我们可以定义**todoChain**，然后在内部用 agent 处理提示词，而关于待办的任务我们再将其封装成 **tool**。

在项目代码中，我们可以做如下目录结构设置&#x20;

```go
AIWorkHelper
 └── internal
      └── logic
           └── chatinternal
                ├── toolx
                └── todohandle.go

```

* **AIWorkHelper**：项目的根目录

* **internal**：内部实现目录，通常放业务逻辑，不对外暴露

* **logic**：主要存放业务逻辑代码

* **chatinternal**：与聊天（chat）相关的内部逻辑模块

* **toolx**：工具相关的封装（比如前面提到的封装成 tool 的功能）

* **todohandle.go**：处理待办任务的 Go 文件，和前面提到的 `todoChain`、`agent` 逻辑呼应

那么调用的话就有两种方式：

1. **直接通过 new 的方式调用方法：**&#x5C06;调用AI的tool封装成一个业务主&#x4F53;**，**&#x8FD9;种方式就是类似于我们的主体业务，比如审批，待办这些，在logic下创建一个具体的业务对象，然后去调用。

2. **通过 curl 的方式调用主体业务：**&#x8FD9;种方式就是将tool完全抽离出来，作为一个工具来使用

在实现上，可以选择以上两种方案。但在项目采用的是 **基于 curl 的方式调用**，而不是 `new`。**为什么不采用 new 的原因主要有以下三点：**

1. **代码耦合度高**：使用 new 的方式可能会导致代码交织复杂，耦合性太强。

2. **不利于扩展和维护**：后期改动或增加功能时会比较困难。

3. **curl 方式更灵活**：不仅方便解耦，而且在后续如果需要将 `AIChat` 独立出来作为单独服务时，也能很方便地进行拆分和调用。

# 3. Curl封装

以下代码是关于curl的封装，项目中将curl封装在`/AIWorkHelper/pkg/curl/curl.go`文件中

```go
package curl

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
    "net/url"
)

func PostRequest(tokenStr, url string, requestBody any) ([]byte, error) {
    return sendRequest(tokenStr, url, "POST", requestBody)
}

func DeleteRequest(tokenStr, url string, requestBody any) ([]byte, error) {
    return sendRequest(tokenStr, url, "DELETE", nil)
}

func PutRequest(tokenStr, url string, requestBody any) ([]byte, error) {
    return sendRequest(tokenStr, url, "PUT", requestBody)
}

func GetRequest(tokenStr, urls string, queryParams map[string]any) ([]byte, error) {
    // 拼接查询参数
    if len(queryParams) > 0 {
       values := url.Values{}
       for key, value := range queryParams {
          values.Add(key, fmt.Sprintf("%v", value))
       }
       urls = urls + "?" + values.Encode()
    }
    return sendRequest(tokenStr, urls, "GET", nil)
}

func sendRequest(tokenStr, url, method string, requestBody any) ([]byte, error) {

    var (
       body []byte
       err  error
    )

    if requestBody != nil {
       body, err = json.Marshal(requestBody)
       if err != nil {
          return nil, err
       }
    }

    req, err := http.NewRequest(method, url, bytes.NewBuffer(body))
    if err != nil {
       return nil, err
    }

    req.Header.Set("Content-Type", "application/json")
    if len(tokenStr) > 0 {
       req.Header.Set("Authorization", tokenStr)
    }

    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
       return nil, err
    }
    defer resp.Body.Close()

    responseBuffer := new(bytes.Buffer)
    _, err = responseBuffer.ReadFrom(resp.Body)
    if err != nil {
       return nil, err
    }

    return responseBuffer.Bytes(), nil
}
```
